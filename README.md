# CS50P

CS50P is an introduction to programming using Python. It's a course delivered by the Harvard University which covered the topics below :

- Functions, Variables, Conditionals, Loops
- Exceptions
- Third-party libraries
- Unit tests
- File I/O
- Regular Expressions
- Object-Oriented Programming

Find more about this course on their [website][cs50p_material].

The course contains a bunch of problem sets. Some of them can be really challenging.
I created this repository to save all my solutions for those problems. Feel free to try its out, compare its to yours and give me your feedback if needed.
